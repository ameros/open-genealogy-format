# Applying this licensing package

Target repository: https://github.com/ameros/open-genealogy-format

1. Copy `LICENSE` to the repository root.
2. Merge `README-LICENSING-INSERT.md` into the existing `README.md`; do not
   overwrite the project's existing documentation.
3. Copy `COMMERCIAL-LICENSING.md` to the repository root.
4. Review `CONTRIBUTING-LICENSING.md` and decide whether to merge it into the
   existing contribution guide or rename it to `CONTRIBUTING.md` if none exists.
5. Audit dependencies and complete `THIRD-PARTY-LICENSES.md`. Keep all
   upstream notices.
6. Update the GitHub repository “About” description to remove “open-source”
   and say: `Genealogy data format and tools — free for permitted non-commercial use.`
7. Verify that the published source, release archives, and GitHub Pages site
   all show the same licensing position.

The license terms are incorporated by reference through the official URL in
`LICENSE`: https://polyformproject.org/licenses/noncommercial/1.0.0

This package is an implementation aid, not legal advice. In particular, get
legal review if you need to enforce a specific boundary between commercial
and non-commercial activity or use a CLA for future contributions.
